# 抖音数据抓取 · 操作手册

把自己抖音号的作品数据（播放、点赞、评论、分享、收藏、完播率…）每天取一份、存成一张按天累积的表，用来复盘。

**一句话讲清楚它干什么**：用你自己已经登录的浏览器，打开你自己账号的后台，把数据取下来，校验一遍没抄错，再追加进总表。

**边界（先看这条）**：全程**只读你自己账号的数据**。不发布、不改后台任何东西、不碰别人的内容、不代替你登录。

> **如果你只是想用、不打算改代码**：这份工具已经发在 GitHub 上
> （https://github.com/wytnzs/douyin-data-mcp），接给 Agent 只要一行、不用下载也不用配路径。
> 先看 [`接入Agent.md`](接入Agent.md)。这份手册是给「下载到本地自己跑」的人看的。

---

## 一、需要哪些东西配合

只有 **3 样必须的**，其余都是可选。

### 必须

| 组件 | 干什么用的 | 怎么准备 |
|---|---|---|
| **Node.js 22 或更高** | 跑抓取脚本 | 到 nodejs.org 下 LTS 版装上，装完重开终端。终端里输 `node -v` 能看到版本号就成 |
| **Chrome 或 Edge** | 用你浏览器里的登录态去取数 | 一般电脑都有，不用特意装 |
| **抖音号 + 创作者中心权限** | 数据来源 | 抖音 App 里开「创作者中心」就能看到自己的数据 |

**没有第 4 样。** 这套工具**不依赖任何第三方插件、不依赖 Claude Code 专属能力、不需要 npm install**——只用 Node 自带的模块。所以 Claude Code、Codex、WorkBuddy 或你自己在终端里跑，效果完全一样。

### 可选

| 组件 | 什么时候需要 |
|---|---|
| **Claude Code / Codex / WorkBuddy** | 想让它帮你跑、帮你看结论。不装也能跑，就是自己敲命令 |
| **定时任务**（Windows 计划任务 / macOS 的 launchd） | 想每天自动跑一次。不配就每次手动跑 |
| **Obsidian 之类的 Markdown 编辑器** | 看总览文件舒服点。用记事本也能看 |

### 需要一次人工操作

**扫码登录一次**。第一次跑会弹出一个专用浏览器窗口，在里面用抖音 App 扫一次码。之后登录状态存在专用目录里，**不用再扫**。

这一步机器代替不了，也不该代替。

> 之所以要一个「专用浏览器窗口」而不是直接用你天天开的那个：Chrome 从 136 版起，禁止对默认用户目录开调试端口。所以这里永远用一个独立目录（默认 `~/.douyin-data/browser-profile`）。好处是跟你日常浏览器互不干扰，代价就是第一次要单独登一次。

## 二、第一次怎么跑（三步）

### 第 1 步：双击，看到菜单

**Windows**：双击 `启动.bat`
**macOS**：双击 `启动.command`。如果双击没反应（压缩包解压后经常丢掉可执行权限），在终端里跑一次
`chmod +x 启动.command`，或者右键 → 打开。

**它会先自动检查一遍环境**，然后出来菜单：

```
  ────────────────────────────────────────────────

  环境：✅ 就绪（浏览器没在跑，抓取时会自动开）
  数据放在：D:\抖音数据

  ────────────────────────────────────────────────

  1  抓取今天的数据   跑完会更新总览和日志
  2  检查环境         看看缺什么、该怎么补
  3  打开数据文件夹   看看抓到了什么
  4  改数据保存位置   想放 D 盘或别处就按这个

  0  退出
```

菜单顶上那行就是环境状态，不用你手动查：

| 显示 | 意思 |
|---|---|
| `✅ 就绪 · 已登录 某某` | 都好了，直接按 1 |
| `✅ 就绪（浏览器没在跑…）` | 没问题，抓取时它会自己把浏览器开起来 |
| `⚠️ 还没登录抖音…` | 抓取时会弹窗让你扫码 |
| `❌ 有问题（按 2 看详情）` | 按 2 跑详细检查，它会告诉你每一项怎么补 |

**数据放哪儿会一直显示在菜单上。** 默认跟工具放在一起（你解压到哪就在哪，不会偷偷往 C 盘写）。
想换位置按 4，输个路径就行，比如 `D:\抖音数据`，选完它会记住，界面也会立刻刷新。

> 换位置时**旧数据不会自动搬过去**——它会提醒你原来那个目录里已经有数据。想接着用，
> 自己把 `抖音作品数据.csv` 那几个文件复制到新位置。

### 第 2 步：扫码

自检会顺手开好浏览器窗口。切过去，用抖音 App 扫码登录。

扫完回到菜单再按一次 **1**，全部变 ✅ 就往下走。

### 第 3 步：抓第一次

回到菜单按 **2**。跑完会看到（下面数字只是示例，你的条数和校验码都不一样）：

```
✅ 校验通过：23 条作品已落盘 raw/2026-01-01.json
   页面校验码 0123456789abcdef   本机校验码 0123456789abcdef
```

**两个校验码一模一样才算成功**。不一样就重跑一次；还是不一样就停下来别往下走。

按 **3** 可以直接打开数据文件夹，看抓到了什么。

> **不想用菜单**也可以直接在工具目录里跑命令，三平台通用：
>
> ```
> node scripts/check.mjs --launch   # 自检
> node scripts/daily.mjs            # 抓取 + 并表 + 出总览 + 记日志
> ```

## 三、以后每天怎么跑

```
node scripts/daily.mjs
```

一条命令做完：取数 → 校验 → 并表 → 出总览 → 记日志。

- 今天已经抓过 → 自动跳过，不会重复记
- 想重抓今天 → 加 `--force`
- **校验不过就停在取数那步，一个文件都不写**，更不会污染总表

### 想让它每天自动跑

Windows 计划任务 / macOS launchd 里加一条，每天固定时间执行：

```
cd <工具目录> && node scripts/daily.mjs
```

建议设在**下午 1 点之后**——后台的深度指标是次日才补齐的，早抓和晚抓拿到的是同一份，不用赶早。

## 四、抓完看哪里

| 想看什么 | 看哪个文件 |
|---|---|
| 今天抓了没有、校验码是多少 | `抓取状态.md` |
| **账号整体表现 + 每条作品的数据** | `抖音数据总览.md` ← 日常就看这个 |
| 完整历史、要自己算趋势 | `抖音作品数据.csv` |
| 今天的数据对不对 | `raw/日期.json` 配 `raw/日期.sha16` |

`抖音数据总览.md` 长这样：

| 发布日 | 类型 | 标题 | 播放 | 点赞 | 评论 | 分享 | 收藏 | 5秒完播% | 2秒跳出% | 均播秒 |
|---|---|---|---|---|---|---|---|---|---|---|
| 2026-01-01 | 视频 | 你的作品标题会出现在这里 | 1,234 | 56 | 7 | 3 | 12 | 41.20 | 26.50 | 28.30 |

## 五、出问题按这张表查

| 现象 | 真实原因 | 怎么办 |
|---|---|---|
| `未登录：请扫码登录…` | 登录态过期了（抖音会定期踢） | 去浏览器窗口重新扫一次码，再跑 |
| `work_list 返回异常` / 取到 0 条 | 同上，或这个号还没发过作品 | 先确认浏览器里能看到自己的作品列表 |
| 连不上、接口有东西但抓不全 | 后台接口偶发限流 | 脚本自带重试（每请求最多 3 次）。整轮失败就再跑一次 |
| `❌ 校验不一致` | 数据在路上被改动了 | 重跑 `--force`；**再不一致就停手，别并进总表** |
| `寄存区是空的` | 页面被刷新过 | 重跑一次 |
| 浏览器窗口打开了但一直没动静 | 在等你扫码 | 切到那个窗口看看 |
| `端口 9333 没通` | 专用浏览器没起来 | 跑 `node scripts/check.mjs --launch` |
| 端口 9333 被别的程序占了 | 极少数情况 | 换端口：`DOUYIN_CDP_PORT=9444 node scripts/daily.mjs`（Windows PowerShell 用 `$env:DOUYIN_CDP_PORT=9444`） |

## 六、口径备忘（不然复盘会算错）

- **播放量是累计值，不是当日增量**。当日增量 = 今天这行 − 上一天同一条作品。直接拿今天的播放当"今天涨了多少"会错得离谱。
- **指标截至 = 抓取日 − 1 天**。几点抓都一样。
- **总播放会被单条爆款拉偏**。跟自己比的时候看中位数、看"和上一条系列比"更准。
- **新作品当天没有完播率**：后台要次日才算，不是故障。
- **图文作品没有深度指标**：那套接口只算视频。看 `media_type` 列区分，复盘时别把图文和视频混着比。
- **老作品某项突然变 0.00%**：后台指标序列末点缺失，当空值处理，别写进结论。脚本会自动把这类变化标成 ⚠️。

## 七、数据长什么样（17 列）

```
capture_date 抓取日期　aweme_id 作品ID　title 标题　publish_date 发布日
duration_sec 时长秒　view 播放　like 点赞　comment 评论　share 分享　collect 收藏
completion_rate_pct 完播率%　completion_rate_5s_pct 5秒完播率%　bounce_rate_2s_pct 2秒跳出率%
avg_view_sec 平均播放秒　fan_gain 涨粉　metrics_asof 指标截至
media_type 作品类型（视频 / 图文）
```

**有两列永远是空的**：`completion_rate_pct`（单条整体完播率）和 `fan_gain`（单条涨粉）——后台只给账号级的，没开放单条接口。**留空，不做估算填充**。

`metrics_asof` 这列最重要：写的是深度指标实际算到哪天。

## 八、怎么把它交给 Agent 跑

**推荐做法：接 MCP。** 接上之后你只要说一句「抓一下我抖音的数据」，Agent 自己会调，
不用你敲命令、不用记步骤。完整说明见 **[`接入Agent.md`](接入Agent.md)**。

### 一句话接上（Claude Code）

```
node scripts/mcp-config.mjs --install
```

或者手工：

```
claude mcp add douyin -s user -- node "<工具目录>/scripts/mcp.mjs"
```

**WorkBuddy / Codex / Cursor / 其他**：跑 `node scripts/mcp-config.mjs`，
它会算出你机器上的绝对路径，打印出可直接粘贴的配置。放进客户端的 MCP 设置里就行。

接上之后 Agent 会多出 6 个工具（`douyin_status` / `douyin_check` / `douyin_fetch` /
`douyin_merge` / `douyin_daily` / `douyin_data`），它自己决定调哪个。

### 不想接 MCP 的兜底办法

这套工具本身是普通命令行脚本，所以也能让 Agent 照着指令跑：

```text
帮我跑一个抖音数据抓取脚本，目录是 <把这里换成实际路径>。

按顺序做：
1. 先跑 node scripts/check.mjs
   - 如果显示「浏览器调试模式」❌，改跑 node scripts/check.mjs --launch
   - 如果显示「抖音创作者中心登录」❌，停下来告诉我：需要我在弹出的浏览器窗口里扫码，
     等我确认扫完了再继续
2. 全部 ✅ 之后，跑 node scripts/daily.mjs
3. 跑完把结果读给我，重点说这几件事：
   - 浏览器校验码和本机校验码是否一致（不一致就别往下走，直接告诉我）
   - 本次几条、新增几条、更新几条、累计几行
   - 深度指标覆盖了几条、没覆盖的是什么原因
   - 当日播放 Top3
   - 有没有 ⚠️ 指标异常
4. 然后把「抖音数据总览.md」里的账号近 7 天那张表念给我

不要改任何脚本，不要跳过校验，不要替我登录。
```

### 让 Agent 每天自动跑

- 接了 MCP：用 Agent 自带的定时任务调 `douyin_daily` 工具
- 没接 MCP：定时任务里执行 `node scripts/daily.mjs`

## 九、给要改接口的人

数据全部来自你自己账号的后台接口，已实测确认：

| 用途 | 接口 | 坑 |
|---|---|---|
| 账号信息（昵称/粉丝数） | `GET /web/api/media/user/info/` | **未登录时返回 HTTP 200 + `status_code: 8`**，只看 HTTP 状态码会把"没登录"误判成"登录了但没作品" |
| 作品清单 + 播放/点赞/评论/分享/收藏 + 时长 | `GET /janus/douyin/creator/pc/work_list` | `aweme_id` 是字符串，不丢精度 |
| 单条深度指标（5s完播/2s跳出/均播秒） | `POST /janus/douyin/creator/data/item_analysis/item_performance` | **必须先取 `involved_vertical` 带上，否则返回空**；**不含当日发布的作品**；`item_id` 是 int64，JS `JSON.parse` 会丢精度，要从原始文本按序正则取 |
| 垂类参数 | `GET /janus/douyin/creator/data/item_analysis/involved_vertical` | |
| 账号近 7 天总览 | `POST /janus/douyin/creator/data/overview/dashboard` | |
| 粉丝/主页趋势 | `GET /janus/douyin/creator/data/overview/dashboard/fans?recent_days=7` | |

**接口变了只改 `collect.js`**，本手册和其他脚本都不用动。

## 十、文件都是干什么的

```
启动.bat / 启动.command   一键自检 + 启动浏览器（小白入口）
操作手册.md               本文件
接入Agent.md              接给 Agent 用（MCP），推荐先看这个
collect.js                浏览器端取数（在后台页面里跑，结果寄存在浏览器内）
scripts/
  mcp.mjs                 给 Agent 的 MCP server（6 个工具，零依赖）
  mcp-config.mjs          生成各客户端的接入配置（路径自动算好）
  check.mjs               环境自检，缺什么说什么
  browser.mjs             找/启动带调试端口的浏览器
  cdp.mjs                 零依赖的浏览器调试客户端
  daily.mjs             ★ 一条命令跑完
  fetch.mjs               取数 + 落盘 + 双向校验
  merge.mjs               并表（同一天同一作品覆盖，其它日期不动）
  report.mjs              生成总览
抖音作品数据.csv           总表，唯一权威
抖音数据总览.md            日常看这个
抓取状态.md                日志，排障先查它
raw/                      每日原始快照 + 校验码，永久保留
```

### 给开发者的机器可读接口

每个 CLI 都支持 `--json`，会在最后多打一行 `@@RESULT@@{...}`，供上层程序读取：

| 命令 | 退出码 |
|---|---|
| `fetch.mjs` | `0` 成功　`1` 失败　`3` 今天已抓过　`4` 需要用户先登录 |
| `daily.mjs` | 同上 |

`--wait-login=秒` 控制未登录时等多久（CLI 默认 360；MCP 传 `0`，让 Agent 立刻拿到「要扫码」这个事实，而不是把工具调用卡住）。

## 十一、安全与隐私

- 只读自己账号，**不发布、不改后台、不看别人**
- 数据**只存在你自己电脑上**，不上传任何地方
- 专用浏览器目录 `~/.douyin-data/browser-profile` 里存着你的登录态。
  不想要了直接删掉整个目录即可——**不会影响你日常用的浏览器**，只是下次要重新扫码
- 脚本会在本机开一个调试端口（默认 9333），只监听 `127.0.0.1`，外网访问不到。跑完可以直接关掉专用浏览器窗口
